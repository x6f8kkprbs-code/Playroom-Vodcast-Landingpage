# Playroom Studios Podcast & Videopodcast Landingpage – Visual Layout Brief for Claude Code

## Purpose

This document is a visual direction brief for Claude Code.

Use it together with the main content and SEO brief.

Goal:
Refine the landingpage so it feels like a premium creative production studio website with a calm editorial look, strong typography and a polished visual rhythm.

Important:
Do not build this like a startup landingpage.
Do not build this like a SaaS template.
Do not overload the page with cards, icons, badges or visual noise.

The page should feel like a high end service page for a production studio in Frankfurt.

---

---

## Core Visual Principle

The site should feel:

- premium
- editorial
- minimal
- cinematic
- calm
- confident

The visual quality should come from:

- strong typography
- generous spacing
- image scale
- visual restraint
- elegant composition

Not from:

- gimmicks
- gradients
- decorative UI tricks
- too many effects

---

## Overall Design Language

Use a visual language inspired by the existing Playroom Studios website.

Priorities:

- bold but refined typography
- dark elegant tones
- strong contrast with restraint
- clean grid
- large image moments
- premium whitespace
- subtle motion only
- polished mobile layout

Avoid:

- bright startup colors
- playful UI
- loud gradients
- fake dashboard elements
- tiny cards everywhere
- overused rounded SaaS blocks
- too many icons
- busy hero overlays

---

## Hero Direction

### Goal

The hero must immediately communicate:

- podcast and videopodcast production in Frankfurt
- premium production quality
- Playroom Studios as a serious production partner
- visual confidence

### Layout

Use a full width hero image.

Recommended composition:

- full width image with cinematic crop
- content container aligned left or slightly left of center
- very large H1
- short compact supporting text
- two CTAs
- generous padding top and bottom
- dark overlay only if needed for readability
- no floating cards
- no stats
- no badges

### Hero asset

Use:

```text
/public/media/hero-fullwidth.jpg
```

### Typography

H1 should be visually dominant.
Think large, calm and expensive.

Recommended feel:

- desktop H1 very large
- clear line breaks
- compact subline width
- strong button spacing

### Hero mood

The hero should feel like a premium studio website, not a sales page.

---

## Section Rhythm

The page should follow a strong editorial rhythm.

Use this order:

1. Hero
2. Editorial intro section
3. Studio in Frankfurt section
4. 4K videopodcast section
5. Why Playroom section
6. Creative extensions section
7. Full service section
8. Use cases section
9. Workflow section
10. Gallery section
11. FAQ
12. Final CTA

Important:
Each section must feel visually distinct, but still belong to one design system.

---

## Section by Section Visual Direction

### 1. Hero

Visual treatment:
- large full width image
- calm overlay if necessary
- huge typography
- two strong CTAs
- lots of negative space

Avoid:
- cards in hero
- icon rows
- mini features
- cluttered top navigation treatment

---

### 2. Editorial Intro Section

Purpose:
Explain why podcast formats matter.

Visual style:
- editorial two column block
- headline on one side
- text on the other side
- lots of whitespace
- no icons
- no card grid

This section should feel like a premium magazine layout.

---

### 3. Studio in Frankfurt Section

Purpose:
Show physical location and acoustic quality.

Visual style:
- one large studio image
- one strong text block
- side by side layout
- calm spacing
- image should feel important

Use one of the studio images here, ideally the one that best shows the room.

---

### 4. Videopodcast in 4K Section

Purpose:
Show the technical production level.

Visual style:
- alternate the layout direction compared to the previous section
- use text plus image
- optional smaller supporting image below if useful
- no generic feature cards

This section should create rhythm and balance.

---

### 5. Why Playroom Studios Section

Purpose:
Show clear differentiators.

Visual style:
- restrained feature grid
- 4 or 5 modules max
- minimal icons only if absolutely necessary
- typography should do most of the work
- modules should feel premium, not app-like

Spacing is more important than decoration.

---

### 6. Creative Extensions Section

Purpose:
Present motion graphics, CGI, intro music and sound design as an added creative layer.

Visual style:
- slightly denser grid is acceptable here
- 4 content blocks
- refined section heading
- clean modular layout
- elegant dividers or subtle borders if needed
- avoid colorful illustration style

This section should feel like an elevated production capability, not a second business.

---

### 7. Full Service Section

Purpose:
Create confidence that Playroom can handle the process.

Visual style:
- clean structured overview
- can be a split list, clean grid or quiet process-style list
- focus on readability
- no excessive decoration

This section should feel reassuring and organized.

---

### 8. Use Cases Section

Purpose:
Help visitors identify themselves.

Visual style:
- concise use case modules
- short copy
- clear headings
- simple refined layout

This section should be easy to scan.

---

### 9. Workflow Section

Purpose:
Reduce complexity and explain the process.

Visual style:
- elegant five step layout
- horizontal on desktop
- vertical on mobile
- subtle numbering
- no playful timeline graphics

Think premium process visualization, not infographic.

---

### 10. Gallery Section

Purpose:
Create emotional trust and atmosphere.

Visual style:
- editorial gallery
- asymmetrical layout
- a few large images rather than many small ones
- strong cropping
- visual calm
- magazine-like composition

Use studio and lounge images here.

This section is one of the most important for perceived quality.

Avoid:
- standard uniform thumbnail grid
- tiny image boxes
- too many captions

---

### 11. FAQ Section

Purpose:
Support SEO, GEO and objection handling.

Visual style:
- clean accordion
- calm typography
- strong spacing
- minimal UI

Do not make the accordion feel overly styled or playful.

---

### 12. Final CTA Section

Purpose:
Close with confidence.

Visual style:
- strong headline
- short text
- one clear CTA
- visually calm closing block
- darker tone acceptable here

No pressure tactics.

---

## Typography Rules

Typography is a major quality lever.

Requirements:

- strong hierarchy between H1, H2, H3 and body text
- large H1
- large section headlines
- comfortable paragraph width
- clean readable body text
- avoid tiny text blocks
- avoid overly long line lengths

The site should feel premium because the typography is confident and spacious.

---

## Spacing Rules

Spacing should be more generous than default AI layouts.

Requirements:

- more vertical padding between sections
- more breathing room around headings
- larger gaps between blocks where needed
- avoid compressed layouts
- allow the content to breathe

A calm layout will feel more expensive.

---

## Image Rules

Use fewer, larger images.

Preferred usage:

- one strong image in hero
- one important image in studio section
- one important image in videopodcast section
- strong gallery near the end

Avoid:

- too many small pictures
- decorative image clutter
- repeating the same visual pattern too often

---

## Color Rules

Stay close to the Playroom Studios mood.

Use:

- dark elegant base colors
- restrained neutrals
- strong contrast where needed
- subtle premium accents only if appropriate

Avoid:

- bright blues
- neon tones
- loud gradients
- colorful cards

---

## Motion Rules

Keep motion subtle.

Allowed:
- light fade in
- gentle reveal
- soft image transitions
- minimal hover refinement

Avoid:
- parallax overload
- exaggerated scroll effects
- flashy animations
- distracting motion in hero

---

## Mobile Rules

The mobile version must feel premium too.

Important:

- preserve hierarchy
- preserve image impact
- do not stack everything too tightly
- keep buttons easy to tap
- ensure text remains calm and readable
- gallery should remain editorial, not collapse into messy thumbnails

---

## What to Avoid

Do not let Claude generate any of the following:

- generic startup hero
- fake trust badges
- dashboard-like cards
- overly rounded colorful sections
- excessive icon usage
- repeated identical card grids
- cluttered navigation area
- template feeling
- visual overdesign

---

## Visual Quality Check

Before finalizing, Claude should review the result against these questions:

1. Does this look like a premium studio service page rather than a SaaS landingpage?
2. Is the hero calm, large and visually confident?
3. Does the site use enough whitespace?
4. Are there too many cards or icons?
5. Does the gallery feel editorial and high end?
6. Does the mobile version still feel premium?
7. Does the page visually support the Playroom Studios brand?

If any answer is no, refine again.

---

## Final Instruction for Claude Code

Refine the landingpage with a premium editorial visual language that matches Playroom Studios.

Use the provided full width hero image instead of a video.
Make the page feel calm, confident and expensive through layout, type, spacing and image composition.

The final result should feel like a high end production studio website in Frankfurt, not an AI template.
